# 🎬 Netflix Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing **Netflix customer, subscription, content, and revenue data** to uncover meaningful business insights using **Data Cleaning, Feature Engineering, SQL, and Power BI**.

The objective was to transform raw Netflix data into a structured and analysis-ready dataset, perform SQL-based analysis, and develop an interactive **Power BI dashboard** to understand customer behavior, content preferences, subscription performance, and revenue trends.

---

## 🛠️ Tools & Technologies

* **Python / Pandas** – Data Cleaning & Feature Engineering
* **SQL** – Data Analysis & Business Queries
* **Power BI** – Data Visualization & Interactive Dashboard
* **Excel/CSV** – Raw Data Source

---

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Feature Engineering → SQL Analysis → Power BI Visualization → Business Insights**

### 1. 🧹 Data Cleaning

The raw Netflix dataset was cleaned and prepared for analysis by:

* Handling missing and inconsistent values
* Identifying and removing duplicate records
* Correcting data types
* Standardizing categorical values
* Validating customer and subscription-related fields
* Preparing the dataset for SQL analysis and Power BI

### 2. ⚙️ Feature Engineering

New analytical features and categories were created to improve business analysis, including:

* Customer-related categories
* Content type classification
* Subscription plan categories
* Genre-based classifications
* Revenue-related metrics
* Watch-hour and customer engagement categories

### 3. 🗄️ SQL Analysis

SQL was used to perform exploratory and business-focused analysis across customers, content, subscriptions, countries, genres, and revenue.

Key analysis included:

* **Total Customers**
* **Customer distribution by Country**
* **Content Type analysis**
* **Subscription Plan analysis**
* **Favorite Genre analysis**
* **Revenue analysis**
* **Revenue by Subscription Plan**
* **Revenue by different categories**
* Customer and content-related performance analysis

SQL queries were used to aggregate, filter, group, and compare the data to identify important trends and patterns.

---

## 📊 Power BI Dashboard

An interactive Power BI dashboard was created to provide a consolidated view of Netflix's customer and business performance.

### Key Dashboard Metrics

* 👥 **Total Customers**
* 🌍 **Total Countries**
* 🎬 **Content Type Distribution**
* 💳 **Subscription Plan Distribution**
* ❤️ **Favorite Genres**
* 💰 **Total Revenue**
* 📈 **Revenue by Category**
* 💵 **Revenue by Subscription Plan**

### Dashboard Visuals

The dashboard includes interactive visualizations such as:

* KPI Cards
* Bar Charts
* Column Charts
* Donut/Pie Charts
* Category-wise Revenue Analysis
* Country-wise Customer Distribution
* Subscription Plan Analysis
* Genre Preference Analysis
* Content Type Distribution

Interactive filters and slicers allow users to explore the data based on different **countries, content types, subscription plans, genres, and other categories**.

## 🔍 Key Business Questions

The project answers questions such as:

1. How many total customers does Netflix have in the dataset?
2. Which countries contribute the highest number of customers?
3. What is the distribution of different content types?
4. Which subscription plan is most popular?
5. What are the most preferred/favorite genres?
6. What is the total revenue generated?
7. Which subscription plan generates the highest revenue?
8. How does revenue vary across different categories?
9. Which customer/content segments contribute most to overall performance?
10. What patterns can be identified from customer and subscription data?

## 💡 Business Insights

The analysis helps identify:

* Customer distribution across different countries
* Popular subscription plans
* Customer content preferences
* Most preferred genres
* Revenue contribution from different subscription categories
* High-performing customer segments
* Relationship between customer preferences and revenue generation

These insights can help businesses understand **customer behavior, subscription performance, content preferences, and revenue drivers** for better decision-making.
